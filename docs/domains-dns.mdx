# Domains & SSL

## Adding a Domain

```bash
deploy domain add myapp example.com
```

This registers the domain with deploy. The next time you run `deploy up`, Caddy will automatically configure reverse proxy and obtain Let's Encrypt SSL certificates.

## SSL

SSL is handled entirely by Caddy. When you add a domain and Caddy is running:
1. Caddy automatically requests a Let's Encrypt certificate
2. Certificates are auto-renewed
3. HTTP traffic is auto-redirected to HTTPS

No configuration needed.
