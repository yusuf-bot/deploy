# Secrets

deploy stores secrets encrypted at rest using AES-256-GCM. The master key is at `~/.deploy/master.key` with 0600 permissions.

## Usage

```bash
# Set a secret
deploy secrets set myapp DATABASE_URL=postgres://user:pass@host/db

# List secrets (shows keys only)
deploy secrets ls myapp

# Get a secret value
deploy secrets get myapp DATABASE_URL --raw

# Remove a secret
deploy secrets rm myapp DATABASE_URL
```

## How It Works

1. Master key is generated during `deploy init`
2. Secrets are encrypted with AES-256-GCM before storing in SQLite
3. The daemon decrypts secrets at runtime and passes them as container environment variables
4. Secrets override `env` values from `deploy.yml` on key conflict

## Security

- Master key file: `~/.deploy/master.key` — permissions `0600`
- Secrets stored encrypted in SQLite
- Decrypted only in daemon memory during container creation
- CLI never exposes secret values without `--raw`
